coverage, build output, caches, local environment files, and generated Prisma
client files are intentionally collapsed or omitted.

Canonical ownership rules
-------------------------

- Frontend routes: app/
- Frontend implementation: src/
- Backend: backend/learnxai-api/
- Prisma schema and migrations: backend/learnxai-api/prisma/
- Generated Prisma client: backend/learnxai-api/src/generated/prisma/ (ignored)
- Permanent product/execution documentation: AGENTS.md and docs/

There is no root Prisma schema, second backend, or tracked local .env file.
